# fests-exp

Painel de festivais de cinema experimental, publicado em https://fests-exp.vercel.app

- `index.html` é a página inteira (dados, estilo e script num arquivo só).
- Cada push na branch `main` publica uma versão nova no Vercel automaticamente.
- Para atualizar prazos e festivais, peça ao Claude: "atualiza o painel de festivais".
